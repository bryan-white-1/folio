# Tables and headings

Choose Paragraph or H1–H6 from the heading picker. Ctrl+Alt+1–6 applies a heading; Ctrl+Alt+0 restores a paragraph. Both rendered and source views support the same levels.

## Table editing

Right-click a table cell, or press Shift+F10, to insert, delete, select or align rows and columns. The same menu provides Clear contents and Delete table.

<!-- folio:table:v1 widths=160,260,140 -->

| Feature | Action | Scope |
| :--- | :--- | :---: |
| Rows and columns | Insert before/after or delete | Selection |
| Column alignment | Left, center or right | Columns |
| Cell selection | Drag or use row/column selection | Range |
| Clear contents | Select cells and press Delete | Range |

Tab/Shift+Tab moves between cells. Tab in the final cell adds a row. Enter moves to a paragraph outside the table. Ctrl+Z undoes each change.
