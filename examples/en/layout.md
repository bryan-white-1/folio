# Table and image sizes

Drag a table column boundary to resize it. Select an image and use its lower-right handle or pixel input. Sizes are restored when you save and reopen the document.

<!-- folio:table:v1 widths=160,360 -->

| Item | Instructions |
| :--- | :--- |
| Column width | Drag a vertical boundary left or right |
| Image size | Drag the handle or enter 40–2400 px |
| Original size | Use the Original button on the image |
| Edit history | Ctrl+Z and Ctrl+Y |

![Resizable example](assets/layout-sample.svg "An image with its aspect ratio preserved")<!-- folio:image:v1 width=420 -->

The same image can have a different size in each occurrence.

![Small example](assets/layout-sample.svg)<!-- folio:image:v1 width=180 -->

Dimensions are stored in HTML comments. Other Markdown viewers may ignore these size hints.
