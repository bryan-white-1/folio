# 표·이미지 크기 조절

표의 세로 경계선을 드래그해 열 너비를 조절하세요. 이미지는 클릭한 뒤 우하단 손잡이 또는 px 입력을 사용하세요. 저장 후 다시 열면 지정 크기를 복원합니다.

<!-- folio:table:v1 widths=160,360 -->

| 항목 | 사용법 |
| :--- | :--- |
| 표 열 너비 | 세로 경계선을 좌우로 드래그 |
| 이미지 크기 | 손잡이 드래그·40–2400px 입력 |
| 원본 복원 | 이미지 위 원본 버튼 |
| 편집 이력 | Ctrl+Z·Ctrl+Y |

![크기 조절 예시](assets/layout-sample.svg "비율을 유지하는 이미지")<!-- folio:image:v1 width=420 -->

동일 이미지도 다른 크기를 저장할 수 있습니다.

![작은 예시](assets/layout-sample.svg)<!-- folio:image:v1 width=180 -->

크기는 HTML 주석에 저장합니다. 일반 Markdown 뷰어에서는 지정 크기를 적용하지 않습니다.
