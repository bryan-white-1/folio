# 표·제목 편집

상단 **본문·제목 선택기**에서 본문 또는 H1–H6을 선택한다. Ctrl+Alt+1–6은 제목, Ctrl+Alt+0은 본문. 원문·렌더링에서 같은 레벨을 적용한다.

## 표 편집 도구

표 셀을 클릭하면 행·열·정렬·더보기 도구가 나타난다. 우클릭 또는 Shift+F10도 지원한다. 행/열 메뉴에서 추가·삭제·선택, 더보기에서 내용 지우기·표 삭제를 실행한다.

<!-- folio:table:v1 widths=160,260,140 -->

| 기능 | 조작 | 우선순위 |
| :--- | :--- | :---: |
| 행·열 편집 | 선택 범위 앞/뒤 추가·삭제 | 1차 |
| 열 정렬 | 왼쪽·가운데·오른쪽 | 1차 |
| 셀 범위 선택 | 드래그, 행/열 선택 메뉴 | 1차 |
| 내용 지우기 | 셀 범위 선택 후 Delete | 1차 |

Tab/Shift+Tab으로 셀을 이동한다. 마지막 셀에서 Tab을 누르면 행이 하나 추가된다. Enter는 표 밖 문단으로 이동한다. Ctrl+Z로 변경을 한 단계씩 취소한다.
